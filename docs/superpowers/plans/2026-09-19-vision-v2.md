# Vision v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `render_plate_view` produce images an agent can read — located, labelled, lit — with the numbers that make them checkable, plus named cameras and a first-layer plan view.

**Architecture:** The GL pass stays in `OrcaMCPPlateUtils.cpp` (`RenderThumbnail`, now drawing into its own framebuffer) and grows a `RenderReport` of what it drew. Everything visual that is new is 2D: overlays and the first-layer plan are drawn with wx on the finished `wxImage`, projecting 3D points through the render camera's own matrices. All geometry/colour/camera decisions live in pure functions in a new GL-free file so they can be unit-tested in `tests/slic3rutils`.

**Tech Stack:** C++17, Eigen (`Vec3d`, `Matrix4d`), wxWidgets (`wxImage`, `wxMemoryDC`, `wxGraphicsContext`), nlohmann::json, Catch2, glad (never GLEW).

**Spec:** `docs/superpowers/specs/2026-09-19-vision-v2-design.md`

## Global Constraints

- All coordinates the tool accepts or reports are **bed millimetres** ("the get_scene_info frame") unless a view says `frame: "plate_local"`.
- Palette: 12 colours, contrast-chosen for a light background; colour of object *i* = palette[i % 12]; wipe tower stays `ColorRGBA(0.75f, 0.76f, 0.80f, 1.0f)`.
- Background clear colour `(0.93f, 0.93f, 0.93f, 1.0f)`; `emission_factor` 0.3.
- Files are written as PNG; inline base64 stays JPEG unless `image_format: "png"`.
- No GL text. No new GL entry points beyond those already used (all through glad).
- `-Werror` is on: every override marked, no unused captures, no signed/unsigned warnings.
- Verification against the live app uses `/tmp/claude-501/frame-test.3mf` (a copy outside protected folders) and `render_probe.sh`-style checks; the app is closed with the `quit_app` tool, never by signal or AppleScript.
- Never push a tag. Version bump to `2.5.0.3-dev` is the last commit.

- [ ] **Step 1: Register the tool**

```cpp
    register_tool({
        "quit_app",
        "Quit OrcaMCP cleanly without any dialog. Default discards unsaved project changes; pass "
        "discard_changes=false to refuse when the project is dirty (then call save_project first).",
        {{"type", "object"},
         {"properties", {{"discard_changes", {{"type", "boolean"}, {"description", "Discard unsaved changes (default true)"}}}}}},
        [](const nlohmann::json& params) -> nlohmann::json {
            const bool discard = params.value("discard_changes", true);
            return run_on_main_thread([discard]() -> nlohmann::json {
                Plater* plater = wxGetApp().plater();
                if (!discard && plater != nullptr && plater->is_project_dirty())
                    return error_response("project has unsaved changes; call save_project first or pass discard_changes=true");
                // Close(true) forces: wxCloseEvent::CanVeto() is false, so MainFrame::on_close never asks
                // "save changes?" and never opens a file dialog. Scheduled so this reply is sent first.
                wxGetApp().CallAfter([]() {
                    if (wxGetApp().plater() != nullptr) wxGetApp().plater()->reset_project_dirty_after_save();
                    wxGetApp().mainframe->Close(true);
                });
                return nlohmann::json{{"status", "quitting"}};
            });
        }
    });
```

```cpp
// OrcaMCPRenderMath.cpp (key bodies)
bool project_point_to_pixel(const CameraFrame& c, const Vec3d& w, Vec2d& px) {
    Eigen::Vector4d clip = c.projection * (c.view * Eigen::Vector4d(w.x(), w.y(), w.z(), 1.0));
    if (std::abs(clip.w()) < 1e-12) return false;
    const Eigen::Vector3d ndc = clip.head<3>() / clip.w();
    if (clip.w() < 0.0) return false;                                       // behind the camera
    const double vx = c.viewport[0], vy = c.viewport[1], vw = c.viewport[2], vh = c.viewport[3];
    px.x() = vx + (ndc.x() + 1.0) * 0.5 * vw;
    px.y() = vy + (1.0 - (ndc.y() + 1.0) * 0.5) * vh;                       // top-left origin
    return true;
}
ScreenBBox screen_bbox_of(const CameraFrame& c, const BoundingBoxf3& box) {
    ScreenBBox out; bool any = false; double x0 = 1e300, y0 = 1e300, x1 = -1e300, y1 = -1e300; int behind = 0;
    for (int i = 0; i < 8; ++i) {
        Vec3d corner((i & 1) ? box.max.x() : box.min.x(), (i & 2) ? box.max.y() : box.min.y(), (i & 4) ? box.max.z() : box.min.z());
        Vec2d p; if (!project_point_to_pixel(c, corner, p)) { ++behind; continue; }
        any = true; x0 = std::min(x0, p.x()); y0 = std::min(y0, p.y()); x1 = std::max(x1, p.x()); y1 = std::max(y1, p.y());
    }
    if (!any) return out;
    const double vx0 = c.viewport[0], vy0 = c.viewport[1], vx1 = vx0 + c.viewport[2], vy1 = vy0 + c.viewport[3];
    out.clipped = behind > 0 || x0 < vx0 || y0 < vy0 || x1 > vx1 || y1 > vy1;
    out.x0 = std::max(x0, vx0); out.y0 = std::max(y0, vy0); out.x1 = std::min(x1, vx1); out.y1 = std::min(y1, vy1);
    out.visible = out.x1 > out.x0 && out.y1 > out.y0;
    return out;
}
ColorRGBA object_palette_color(int i) {
    static const ColorRGBA k[12] = {
        {0.20f,0.47f,0.85f,1}, {0.89f,0.35f,0.24f,1}, {0.22f,0.66f,0.36f,1}, {0.93f,0.62f,0.13f,1},
        {0.58f,0.34f,0.78f,1}, {0.10f,0.62f,0.66f,1}, {0.80f,0.25f,0.55f,1}, {0.52f,0.58f,0.12f,1},
        {0.36f,0.36f,0.76f,1}, {0.85f,0.45f,0.45f,1}, {0.16f,0.50f,0.44f,1}, {0.62f,0.45f,0.25f,1}};
    return k[((i % 12) + 12) % 12];
}
void preset_camera(CameraPreset p, const BoundingBoxf3& fit, Vec3d& pos, Vec3d& target) {
    target = fit.center(); const double d = std::max(50.0, 2.2 * fit.size().norm()); const Vec3d s = fit.size();
    switch (p) {
    case CameraPreset::Iso:   pos = target + Vec3d( 0.60,-0.60, 0.52).normalized() * d; break;
    case CameraPreset::Top:   pos = Vec3d(target.x(), target.y() - 1e-3 * d, fit.max.z() + d); break;   // tiny y offset: stable up
    case CameraPreset::Front: pos = target + Vec3d(0,-1, 0.35).normalized() * d; break;
    case CameraPreset::Back:  pos = target + Vec3d(0, 1, 0.35).normalized() * d; break;
    case CameraPreset::Left:  pos = target + Vec3d(-1,0, 0.35).normalized() * d; break;
    case CameraPreset::Right: pos = target + Vec3d( 1,0, 0.35).normalized() * d; break;
    case CameraPreset::Low:   pos = Vec3d(target.x(), fit.min.y() - d, fit.min.z() + 0.05 * s.z() + 5.0); target.z() = fit.min.z() + 0.1 * s.z(); break;
    }
}
```

`is_uniform_rgba`: compare every 4-byte pixel to the first. `grid_segments`: for x from ceil(min.x/step)*step to max.x inclusive emit (x,min.y,0)-(x,max.y,0), major when `lround(x/step) % major_every == 0`; same for y.
